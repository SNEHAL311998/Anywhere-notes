# Anywhere Notes Manager 📝

A streamlined VS Code extension to manage your notes in one central location, regardless of which project or workspace you are currently working in.

## Features

- **Global Storage:** Set one folder on your computer to hold all your notes.
- **Workspace Independent:** Create and access notes from any VS Code window.
- **Sub-folder Support:** Organize notes using slashes (e.g., `Work/ProjectA/Todo`).
- **Status Bar Integration:** Always see your current notes directory at a glance.

## 🛠️ Getting Started

1. **Install** from the [VS Marketplace](https://marketplace.visualstudio.com/items?itemName=Snehal.snehal-anywhere-notes) or [Open VSX](https://open-vsx.org/extension/Snehal/snehal-anywhere-notes).
2. **Set Storage:** Open the Command Palette (`Ctrl+Shift+P`) and run **"Notes: Set Storage Folder"**.
3. **Take a Note:** Use the shortcuts below to start documenting instantly.

## ⌨️ Keyboard Shortcuts

| Action            | Windows/Linux    | macOS           |
| :---------------- | :--------------- | :-------------- |
| **Add New Note**  | `Ctrl + Alt + C` | `Cmd + Alt + C` |
| **Create Folder** | `Ctrl + Alt + F` | `Cmd + Alt + F` |

> **Pro Tip:** We switched from `Ctrl+Alt+N` to `Ctrl+Alt+C` to ensure compatibility with international keyboard layouts!

## ⚙️ Extension Settings

- `anywhere-notes.notesFolderPath`: The absolute path to your chosen global notes directory.
